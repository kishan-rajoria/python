# Data Science Mathematics and Statistics Lectures

This repository contains lecture notes and accompanying Python code examples for essential Mathematics and Statistics concepts relevant to Data Science.

## Structure

The repository is organized into folders, each corresponding to a key topic in the syllabus:

1.  `1_Introduction_to_Data_Science/`
2.  `2_Basic_Mathematics_for_Data_Science/` (Linear Algebra, Calculus)
3.  `3_Probability_Theory/`
4.  `4_Descriptive_Statistics/`
5.  `5_Inferential_Statistics/`
6.  `6_Regression_Analysis/`
7.  `7_Advanced_Topics/` (Time Series, Intro to ML)
8.  `8_Practical_Applications/`
9.  `9_Conclusion/`

Each topic folder contains:
*   `README.md`: Detailed notes and explanations of the concepts for that topic.
*   `code.py`: Python code examples illustrating the concepts discussed.

## Usage

1.  **Navigate:** Browse the folders to explore different topics.
2.  **Read:** Review the `README.md` file in each folder for theoretical understanding.
3.  **Run Code:** Execute the `code.py` files to see practical examples. Make sure you have the necessary libraries installed (see `requirements.txt`).

## Requirements

You need Python installed, along with the libraries listed in `requirements.txt`. You can install them using pip:

```bash
pip install -r requirements.txt
```
